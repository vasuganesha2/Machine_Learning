# Machine Learning Algorithms in C++

This project implements core machine learning algorithms from scratch in **C++**, aimed at understanding the fundamentals and internal mechanics of each model. It primarily focuses on classification and clustering techniques tested on the MNIST dataset.

---

## 📁 Project Structure

### `mnist_ml/`
Main directory containing all source code and modules.

- `DT/`  
  Implements **Decision Tree** for classification tasks.

- `GMM/`  
  Contains code for **Gaussian Mixture Models**, a probabilistic clustering algorithm using EM.

- `KMEANS/`  
  Implements the **K-Means** clustering algorithm for unsupervised learning.

- `KNN/`  
  Code for **K-Nearest Neighbors**, a simple instance-based learning algorithm.

- `NEURAL_NETWORK/`  
  Implements a **Feedforward Neural Network** with backpropagation.

- `PCA/`  
  Contains **Principal Component Analysis** for dimensionality reduction.

- `logistic/`  
  Implements **Logistic Regression** for binary classification.

- `svm/`  
  Code for **Support Vector Machine** classifier using margin-based optimization.

- `include/`  
  Header files and shared interfaces used across modules.

- `src/`  
  General source files and main functions to run the models.

- `lib/`, `obj/`  
  Build directories for compiled objects and libraries.

- `.vscode/`  
  Visual Studio Code settings for IntelliSense and debugging.
